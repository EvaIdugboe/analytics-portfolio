# Eva Idugboe | Analytics Portfolio

A selection of data analysis case studies examining customer behaviour, digital marketing performance and commercial outcomes. The focus is on how evidence can inform business decisions, with the assumptions and limitations stated clearly.

## Featured projects

### [AfriTech Electronics | Revenue, Customer and Product Risk Analysis](AfriTech_Electronics/README.md)
**PostgreSQL · SQL · Power BI · DAX**

A case study investigating AfriTech's revenue decline, customer revenue concentration, product recall exposure and social media performance. Includes a live four-page Power BI report, selected aggregated charts, read-only SQL examples and methodology notes.

## Approach

The work combines business-question framing, data exploration, metric checks, dashboard analysis and recommendations. Proposed actions are not presented as business outcomes already achieved.

## Public sharing

These are portfolio case studies. AfriTech uses fictional/synthetic project data, which the project owner has confirmed is cleared for public sharing. Raw data files and the `.pbix` project file are not stored in this GitHub repository. The linked Power BI report is publicly accessible through Microsoft's Publish to web feature, which may expose its underlying report data. All reported commercial metrics relate to the case-study data.
